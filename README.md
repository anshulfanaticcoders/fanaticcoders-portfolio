# FanaticCoders Portfolio

Premium dark-theme portfolio and admin system for FanaticCoders.

## Stack

- Next.js App Router with TypeScript
- Tailwind CSS
- Supabase planned for auth, Postgres, and storage
- Motion/GSAP planned for premium animation
- Playwright planned for end-to-end checks

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment

Copy `.env.example` to `.env.local` when Supabase credentials are available.

Do not commit real secrets.
