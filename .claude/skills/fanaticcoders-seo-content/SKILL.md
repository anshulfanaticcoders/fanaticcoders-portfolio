# FanaticCoders SEO Content

Use this skill for SEO structure, metadata, search-focused service pages, schema, and content quality.

## SEO Defaults
- Treat each service as a focused landing page with a clear client intent.
- Use natural expert copy. Avoid keyword stuffing and generic agency claims.
- Every indexable page needs title, description, canonical URL, and Open Graph metadata.
- Add JSON-LD where it matches the page: Organization, WebSite, Service, Person, BreadcrumbList, and Article/CaseStudy style content when appropriate.

## Page Types
- Home: brand, service overview, proof, team signal, project proof, contact path.
- Services index: scannable service categories and outcomes.
- Service detail: problem, deliverables, process, stack, proof, FAQ, CTA.
- Team: roles, expertise, credibility, social proof.
- Project detail: challenge, solution, stack, results, images, CTA.
- Contact: service interest and lead capture.

## Content Rules
- Write for clients first and search engines second.
- Mention technologies only when they support an outcome.
- Use FAQs for real buying questions.
- Keep headings specific and credible.
- Avoid fake metrics or invented client names.

## Technical Rules
- Generate sitemap and robots once routes exist.
- Keep slugs stable.
- Use dynamic metadata from Supabase for CMS-managed pages.
- Ensure uploaded images include alt text and dimensions.

## Output
- Provide metadata fields and recommended schema per page type.
- Include acceptance checks for title length, descriptions, canonical, OG image, and structured data.
